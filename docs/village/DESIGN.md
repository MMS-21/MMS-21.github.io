# Village prototype

Desktop experience at `/village/`, separate from the existing homepage. The paper background, self-hosted portfolio type, blue flowers, and Moaaz avatar connect the scene to the current site.

The map is original SVG artwork authored for this project. No Kenmi pack files are included. Existing paper fibers and avatar assets are reused locally. Buildings, scenery, animals, paths, and the fountain are code-native vectors.

Six destinations surround a village square: house (about), workshop (projects), cinema (homepage experience timeline), newspaper stand (writing), post office (contact), and backyard (feeding interaction). Building selection updates the adjacent note and moves a visitor; navigation requires the note's explicit link. A text directory provides an equivalent way to select every place. Buildings support Enter and Space. Reduced motion and a visible pause control suppress ambient animation. Narrow screens retain a horizontally scrollable desktop composition; mobile design is deferred by request.

## Direction contract

THESIS: A village on paper acts as a spatial directory into the existing portfolio, with the backyard as a personal moment.

OWN-WORLD: Ivory paper, sage terrain and trees, muted blue roofs and water, wood-coloured outlines, self-hosted Cormorant display type and Manrope controls. Original vector buildings carry readable signs.

STORY: Visitors choose a place, read its note, and open the related work. Feeding chickens adds a short optional interaction.

FIRST VIEWPORT: The village occupies the left of the desktop canvas. A narrower right margin holds the selected place's note, action, and six-place directory. Classic portfolio navigation remains at the top.

FORM: User-selected village layout with a central house, fountain, five surrounding destinations, and winding paths. No randomized direction selection applies to this pinned concept.

FINISH: Desktop browser review completed. All six selections, destination links, keyboard activation, chicken feeding, and motion pause were checked. Production build produces the separate route. This is a first interactive prototype, not an adaptation of the licensed fantasy pack.
