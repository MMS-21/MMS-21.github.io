# Portfolio workflow

The user wants committed portfolio changes published automatically. After completing and validating requested changes, commit the relevant files, push to `origin/main`, and check the GitHub Pages deployment. Do not ask for repeated publication approval. Integrate remote changes without overwriting them; never force-push. Report the live URL and any deployment failure honestly.

Leave unrelated local files out of task commits.

Use no em dashes in newly written user-facing copy or replies. Use "Confidential" exactly when identifying the withheld HR case-study organization. Exclude its Excel assessment and supplied task instructions from publication.
